堀江　新

回路設計は原と堀江で行った。

---- メモ ----
mosfetは複数の企業が販売しているが、大きさは規格化されている。(例　TO220)
　　(レギュレータなども同規格で表されることが多い)

表面実装はSMD、スルーホールはTHTで表される

スルーホールの部品の足を切って、基盤に表面実装することをリードフォーミングという
stagger_odd とstagger_evenについて
　　リードの曲げ方。
　　stagger_oddは奇数を曲げる
　　stagger_evenは偶数番目で曲げる
　　ショートしにくいのはstagger_even

基本的に、スルーホールのfetであれば、リードにはんだ付けする
タブはドレインになっていることが多いが、放熱用なので、基盤にねじ固定することが主流
